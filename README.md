# Практикум «Администрирование сетевых ОС»

Учебное веб-приложение на Laravel 9 + Bootstrap 5 для прохождения практических работ по администрированию Windows Server и Linux.

## Возможности первого этапа

- регистрация и авторизация пользователей;
- роли `admin` и `student`;
- административная панель;
- управление пользователями через AJAX;
- управление разделами и темами практикума через AJAX;
- каждая тема хранится в БД и открывается как отдельная страница;
- публикация/скрытие и сортировка тем;
- Bootstrap 5 интерфейс без SPA-фреймворка.

## Запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Администратор после `db:seed`:

- Email: `admin@example.com`
- Password: `admin12345`

Пароль рекомендуется изменить после первого входа.
